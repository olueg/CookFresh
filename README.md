# 🍳 CookFresh

> **A native macOS recipe manager and kitchen assistant built with SwiftUI.**

CookFresh is a modern, native macOS application designed to streamline your cooking workflow. It goes beyond a simple digital cookbook by acting as an intelligent kitchen assistant right on your Mac—helping you organize your favorite meals, plan grocery shopping, and guiding you step-by-step through the cooking process.

---

## ✨ Features

- **Smart Kitchen Assistant:** Hands-free or step-by-step guidance designed for a desktop/laptop placement on your kitchen counter.
- **Recipe Management:** Easily import, organize, edit, and categorize your favorite recipes.
- **Dynamic Scale & Convert:** Automatically adjust ingredient portions based on servings.
- **Shopping Lists:** Generate organized grocery lists directly from your selected recipes.
- **Native Experience:** Built exclusively for macOS with support for Dark Mode, keyboard shortcuts, and a clean Apple-style interface.

## 🛠️ Tech Stack

- **Framework:** SwiftUI
- **Language:** Swift 6.0
- **Database:** SwiftData 
- **Platform:** macOS 27+ 

## 🚀 Getting Started

### Prerequisites
- A Mac running macOS Golden Gate (27.0) or later.
- Xcode 27 or later installed.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/olueg/CookFresh.git
   ```
2. Open the project in Xcode:
   ```bash
   cd CookFresh
   open CookFresh.xcodeproj
   ```
3. Resolve Swift Packages (if any) and press `⌘R` to build and run the app.
